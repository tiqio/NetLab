# Data Model: NetLab Network Simulator Platform

**Date**: 2026-07-23

## Conventions

- IDs are UUIDv7 strings generated by the server.
- Mutable aggregate roots have an integer `revision`, incremented once per committed mutation.
- Times are UTC RFC 3339 with microsecond precision.
- Durable enums are lowercase strings; unknown enum values are rejected on writes and preserved as
  explicit compatibility errors on reads.
- JSON configuration fields are schema-versioned and validated before commit.
- Secrets are referenced by opaque secret IDs and never stored in exports, events, or audit payloads.
- Deletion is explicit lifecycle state followed by hard deletion after owned runtime resources and
  dependent records are reconciled.

## Aggregate Relationships

```text
Laboratory 1 ── * Node 1 ── * Interface
Laboratory 1 ── * Link * ── 2 Interface
Laboratory 1 ── * NetworkObject
Laboratory 1 ── * CaptureSession
Laboratory 1 ── * TrafficFilter
Laboratory 1 ── * OperationTask

DeviceTemplate 1 ── * TemplateVersion * ── 1 ImageVersion
Node * ── 1 TemplateVersion
Node 1 ── * PortMapping
Node 1 ── * BootstrapProfile

OperationTask 1 ── * TaskStep
OperationTask 1 ── * AuditEvent
CaptureSession 0..1 ── 1 Artifact
LaboratoryExport 1 ── 1 Artifact
Durable mutation 1 ── 1..* OutboxEvent
```

## Laboratory

| Field | Type | Rules |
|---|---|---|
| `id` | UUIDv7 | Primary key |
| `name` | string | 1–128 characters, unique case-insensitively |
| `description` | string | Maximum 4096 characters |
| `revision` | integer | Optimistic concurrency token |
| `recovery_policy` | enum | `auto_restore` or `remain_stopped`; default `auto_restore` |
| `lifecycle_state` | enum | `active`, `deleting`, `delete_failed` |
| `last_running_snapshot_at` | timestamp? | Time the pre-host-restart running set was recorded |
| `created_at`, `updated_at` | timestamp | Required |

Deletion is allowed only through a task. New mutations are rejected while `deleting`.

## DeviceTemplate and TemplateVersion

`DeviceTemplate` is the stable family (`fancywan`, `ubuntu-qemu`, `fortigate`, `vyos`,
`busybox-container`, `ubuntu-container`). `TemplateVersion` is immutable after a node references it.

### Node State Transitions

```text
stopped -> provisioning -> starting -> running
running -> stopping -> stopped
any non-deleted -> deleting -> deleted
provisioning|starting|running|stopping|deleting -> failed
failed -> provisioning|starting|stopping|deleting after reconciliation decision
unknown -> observed state after adoption scan
```

`desired_state` is authoritative intent. `observed_state` is adapter observation and never directly
set by clients.

| Field | Type | Rules |
|---|---|---|
| `id`, `laboratory_id` | UUIDv7 | Required |
| `endpoint_a_id`, `endpoint_b_id` | UUIDv7 | Distinct, same laboratory |

Point-to-point interfaces cannot belong to two connected links. Shared bridge/network objects accept
multiple interface attachments through `NetworkAttachment` records.

## NetworkObject and NetworkAttachment

`NetworkObject.kind` is `bridge`, `nat_bridge`, `pc`, `switch_l2`, or `switch_l3`. Configuration is
schema-validated for addresses, DHCP/SLAAC modes, routes, forwarding, DNS, NAT, and port membership.
`NetworkAttachment` joins an interface to a network object and stores desired and observed attachment.

NAT objects own internal prefixes, gateway addresses, allocation records, uplink selection, nftables
rule IDs, and cleanup state. Overlapping internal prefixes in the same host routing domain are rejected
unless isolation makes the overlap unambiguous.

## PortMapping

Unique constraint: `(host_protocol, host_address, host_port)` among active mappings.

Fields include node ID, host protocol/address/port, guest address/port, desired/observed state,
owned nftables rule IDs, task ID, and last error. Mappings transition `pending -> active -> deleting ->
deleted`, with `failed` reachable from each transitional state.

## OperationTask and TaskStep

| Field | Type | Rules |
|---|---|---|
| `id` | UUIDv7 | Primary key |
| `kind` | string | Stable operation name |
| `resource_type`, `resource_id` | string, UUIDv7 | Target |
| `idempotency_key` | string? | Unique with operation scope |
| `requested_revision` | integer? | From `If-Match` |
| `state` | enum | `queued`, `running`, `cancelling`, `succeeded`, `failed`, `cancelled` |
| `progress_current`, `progress_total` | integer | Non-negative |
| `result`, `error` | JSON? | Mutually exclusive terminal payloads |
| `cancel_requested_at` | timestamp? | Cooperative cancellation |
| `created_at`, `started_at`, `finished_at` | timestamp | Lifecycle timestamps |

`TaskStep` stores checkpoint order, adapter action, state, attempts, timeout, result/error, and
compensating action state. Terminal tasks are immutable except for retention metadata.

## CaptureSession, Artifact, and TrafficFilter

### CaptureSession

Fields include lab/source IDs, BPF expression, state, start/end times, byte/packet counts, size/time
limits, stream token hash, retained artifact ID, retention expiry, truncation flag/reason, and error.

State transitions: `requested -> starting -> streaming -> stopping -> completed`; `cancelled`, `failed`,
and `truncated` are terminal. Expiry removes the artifact but preserves bounded metadata/audit history.

### Artifact

Kinds: `capture`, `lab_export`, `seed_iso`, `image_staging`. Fields include internal path, media type,
size, SHA-256, owner type/ID, created/expiry times, and deletion state. External clients receive opaque
artifact IDs and time-limited stream handles, never filesystem paths.

### TrafficFilter

Fields include match expression, compiled BPF, selected observation scope, state, counts, first/last
match, and expiry. `TrafficObservation` records a bounded packet fingerprint, interface/link ID,
direction, timestamp, and length. Aggregates expose observed link sets and ordered observations when
timing supports ordering; ambiguous paths remain explicit.

## LaboratoryExport

Fields include lab ID/revision, schema version, task/artifact ID, state, redaction report, missing
dependency report, checksum, and expiry. Import validates the complete bundle before committing a new
laboratory and never substitutes a missing template or image version.

## AuditEvent and OutboxEvent

`AuditEvent` stores actor class (`browser`, `api`, `mcp`, `system`), action, target, task, outcome,
correlation ID, timestamp, and redacted details. There is no user identity model.

`OutboxEvent` stores a monotonically increasing sequence, event type, resource identity/revision,
payload, timestamp, and publication checkpoint. Event retention must exceed the supported client replay
window; clients detecting an expired gap fetch a laboratory snapshot.

## SQLite Constraints and Indexes

- Foreign keys are enabled and validated in migrations.
- Partial unique indexes protect active host ports, MAC addresses, names, and idempotency keys.
- Task indexes cover `(state, created_at)` and `(resource_type, resource_id, created_at)`.
- Outbox sequence is an integer primary key; capture expiry and artifact deletion have scheduled indexes.
- Runtime ownership rows are never cascaded before cleanup reaches a terminal state.
- Schema migrations are forward-only, transactional where SQLite permits, and recorded with checksum.

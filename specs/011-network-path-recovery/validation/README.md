# Validation Evidence

Each milestone records:

- focused commit SHA;
- exact local test commands and results;
- privileged tests skipped locally and their target procedure;
- source candidate, artifact and contract digests;
- migration state and deployment time;
- target health, recovery, connectivity, browser and leak results;
- rollback directory, backup integrity and restoration procedure.

Evidence must be redacted. Do not store credentials, bootstrap secrets, proprietary image contents, packet payloads or unbounded logs.

Planned files are `foundation.md`, `us1-recovery.md`, `us2-dual-stack.md`, `us3-vlan.md`, `us4-vendor.md`, `us5-traffic.md`, `final-local.md`, `deployment.md`, `target-acceptance.md`, `target-browser.md` and `target-cleanup.md`.

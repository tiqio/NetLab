# 前端工作区使用与视觉约束

NetLab 使用接近 EVE-NG 的实验室、拓扑、检查器和底部操作区布局，但所有产品操作文案统一使用简体中文。布局偏好只保存在当前浏览器；实验室、节点、链路、任务、抓包和流量过滤状态仍由服务器共享。

## 工作区结构

- **实验室栏**：切换实验室；通过右键菜单执行重命名、复制、导入、导出和删除。
- **添加资源抽屉**：从最右侧打开，可滚动配置 QEMU、Docker、PC、Bridge、NAT Bridge、Lightweight L2/L3；底部操作不会覆盖表单。
- **拓扑画布**：滚轮缩放，空白区域拖动平移，节点拖动只改变当前浏览器布局；`适应全部` 可恢复可见范围。
- **检查器**：点击节点、链路或网络对象后在右侧显示。标题与操作区固定，详细内容独立滚动。
- **操作区**：任务、终端、抓包、流量过滤和诊断使用独立标签页；切换标签页或刷新页面不会主动停止服务端会话。

## 拓扑可读性

- 节点接口固定分布在四侧轨道上，1、2、4、8、16 接口均使用确定性位置，缩放或拖动后不会重新跳位。
- 接口文字与点击区域分离；连接入口 `+` 与端口区域保持间距，避免误点。
- 多条平行链路使用不同路径和端点标签区分。流量效果只匹配实际观测到的精确链路，不会连带高亮相邻平行链路。
- 链路流量粒子和连接预览不截获鼠标事件；启用系统“减少动态效果”时停止粒子动画。
- 长名称按可用空间截断，完整值通过标题或详细信息访问，不允许覆盖节点状态、端口或操作按钮。

## 中文术语

产品级导航、按钮、菜单、空状态、表单、状态和错误提示必须使用中文。统一术语包括：实验室、拓扑、节点、链路、接口、终端、抓包、流量过滤、任务、模板、镜像、诊断、期望状态和实际状态。

以下技术标识可保留英文或原始值：

- 协议与平台：API、MCP、QEMU、Docker、VNC、Telnet、SSH、Wireshark、Traffic Filter、NAT、IPv4、IPv6、DHCP、SLAAC、QMP、QGA、pcap。
- 资源与性能：CPU、vCPU、RAM、MAC，以及接口名、IP/MAC 地址、端口号、镜像标签和设备型号。
- 原始数据：命令、设备输出、厂商返回信息、错误代码、资源 ID 和用户输入内容。

允许英文不代表允许英文操作说明。技术标识周围的动作、状态和处理建议仍应使用中文。

## 错误呈现

错误按三层展示，避免长文本挤压控件：

1. **摘要**：用中文说明失败动作和当前影响。
2. **原因与建议**：给出可执行的恢复步骤，例如检查接口、重试或安装本机辅助程序。
3. **技术详情**：按需展开原始错误代码、任务 ID 或后端详情，长内容允许换行和滚动。

危险操作必须使用明确的危险样式和二次确认；禁用状态必须同时使用文字或图标说明，不能只依赖浅色差异。

## 布局约束

- 支持浅色、深色主题以及 1024×768、1366×768、1920×1080 视口；关键流程支持浏览器 125% 缩放。
- 检查器图表只在容器具有有效尺寸后初始化，并在尺寸或主题变化后重排。
- 表单、标签页、列表和底部工作区各自管理滚动，不允许页面级溢出隐藏关键按钮。
- 上下文菜单在视口四边自动避让并保持全部菜单项可访问。
- 弹窗、抽屉、菜单、提示、连接预览和流量覆盖属于允许的有意覆盖层，但必须可关闭、可到达且不得遮断目标操作。
- 焦点、选中、禁用、加载、运行、失败和危险状态必须具备可辨认文字或图形语义，并在两种主题下保持可读对比度。

## 发布前检查

新增或修改界面后至少运行：

```bash
./scripts/check-ui-localization.sh
node scripts/check-ui-localization.test.mjs
npm --prefix web test
npm --prefix web run build
./scripts/check-frontend-artifacts.sh
```

涉及布局、主题或交互时，还必须运行 `specs/008-ui-overlap-remediation/quickstart.md` 中的三视口、双主题、125% 和浏览器审计矩阵。

# Evidence Index

Only JSON evidence records conforming to the feature contract belong here. Raw logs, captures,
images, database files, credentials, and bootstrap payloads are prohibited.

`current-candidate.json` is the only aggregate conclusion. It contains candidate identity, per-gate
status and skip reasons, cleanup baseline digests, and redaction counts. Detailed scenario evidence
must be metadata-only JSON and must be referenced from the aggregate before a finding is verified.
